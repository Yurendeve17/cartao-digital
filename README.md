# Cartão Digital — Yuren Deve

React + TypeScript + Vite + Bootstrap 5.

    npm install
    npm run dev      # desenvolvimento
    npm run build    # produção (pasta dist/)

## Onde editar
- Dados pessoais, links, ferramentas, skills: `src/data.ts`
- Portfólio: largue imagens/vídeos em `src/assets/portfolio/<categoria>/` (design-grafico, motion-graphic, ui-ux, web, desenvolvimento). Opcional: `src/portfolio.ts` para links e descrições
- CV: coloque o ficheiro em `public/cv.pdf`
- LinkedIn: troque o link em `src/data.ts` (campo `linkedin`)
- Foto: `public/foto.jpg`
